# Part 1 - OSINT Resources

## Goal
Understand how public resources can support passive reconnaissance.

## Resources Used

### OSINT Framework
Used to discover OSINT resources organized by username, email, domain, IP, social networks and metadata.

### WhatsMyName
Used to understand username enumeration across public services.
A username match alone does not prove that two accounts belong to the same person.

### SMART
Used to discover additional OSINT tools and public resources.

## Key Concepts
- OSINT: intelligence collected from publicly available sources.
- Passive reconnaissance: information collection with minimal direct interaction with the target.
- Pivoting: using one discovered indicator to find another.
- Correlation: comparing information from multiple sources.
- False positive: a result that appears related but is not actually associated with the target.

## Key Lesson
OSINT is a process of collection, validation and correlation rather than a single tool.
